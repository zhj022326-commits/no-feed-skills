# 边界情况

| 情况 | 处理方式 |
| --- | --- |
| 一句话、开头或提纲 | 只分析可见文本；正文兑现、整体内容深度等标“暂无法判断”。不伪装成全文报告。 |
| 立场不明确 | 先判断是否属于无特定立场的分享；仍无证据时标“暂无法判断”。 |
| 没有第三对象 | 知识分享或趣味内容可没有第三对象；不人为制造对立。 |
| 多种传播目的 | 从文本和用户背景判断主次；不强行压缩成单一目的。 |
| 没有产品或服务信息 | 商业覆盖标“缺少产品信息，暂无法判断”；不臆造商业画像。 |
| 理论未覆盖的现象 | 可作为原文观察提出，标明是推断或额外建议；不命名为新理论方法。 |
| 原文有事实争议 | 若影响核心结论，标“待核实”；默认不直接判真假。 |
| 鲜明或绝对化表达 | 先看传播目的和后文兑现；不能仅凭语气强判为缺陷。 |
| 作者目的与平台效果冲突 | 说明取舍依据；没有实测数据时只提供可验证的文本假设。 |
| 用户更新理论 | 当前提供的新版优先；核对定义、分类和版本后再诊断。不要沿用旧理论判断。 |
