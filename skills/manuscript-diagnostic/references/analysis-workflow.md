# 分析工作流程

本文件规定诊断操作，不增加理论分类。每次诊断都先读取完整理论文件。

## 1. 确定输入范围

记录是全文、部分正文、开头、提纲还是一句话；辨认段落边界。文件中的标题、正文、脚注、图表文字若与稿件相关都应读取。缺失的正文不能被视为“没有兑现”。

## 2. 建立稿件画像

用原文提炼核心问题、核心观点、主要与次要传播目的、目标受众、利益归属、作者立场、整体结构、开头的观看期待。作者或用户明示的优先于推断；无证据的项目写“暂无法判断”。不要从受众刻板印象推断年龄、性别、收入等属性。

## 3. 找方法与证据

逐项对照理论原文，只记录实际出现或确有机会的方法。开头检查情绪机制、认知缺口、抬高解释力与兑现；受众检查立场、现实与心理利益、第三对象、三层站队、传播覆盖与有条件的商业覆盖；内容交付检查认知增量与充分表达；统筹与修辞检查取舍、词语与理论匹配、顺着理论深化、理论与内容贴合。

为重要发现记录：理论名称、原文短引文或结构关系、可定位位置、作者可能目的、实际文本作用、证据强弱。没有原文依据时降低结论强度或放弃该判断。

## 4. 分开判断存在与效果

先回答“是否出现该方法”，再回答“它在这篇稿件、这个受众和目的下发挥什么作用”。例如，开头有悬念只证明存在认知缺口；还需检查问题是否明确、是否值得继续看、正文是否回应。正文足够时才能评价兑现；受众反应、播放数据和商业转化没有实测资料时只作文本层面的推断。

使用状态按情境选：已使用且有效；已使用但效果不足；存在优化空间；未使用但不需要；未使用且存在机会。“未使用且存在机会”必须说明它如何服务当前传播目的，不能只因理论列有该方法就建议添加。

## 5. 定位少数关键问题

先写最有价值、应保留的内容，再按影响范围排序问题。问题成立需同时满足：有具体证据；能解释它怎样妨碍既定传播目的、理解或理论贴合；存在可执行的调整方向。对争议性效果用“可能”“需要实测”标注，不把个人偏好写成缺陷。

同一处文字可能关联多个理论模块。各模块解释自己的判断，综合建议只合并一次；若两种理论目标冲突，要说明取舍，不要求同时最大化。

## 6. 生成建议与复核

每条重要建议包括原文位置、问题、影响、具体调整动作和预期改善。可以给局部表达示例，标明只是示例。报告完成后逐一检查建议是否可由前文证据支持，是否改变作者立场，是否与其他建议冲突，是否误把未提供的信息写成事实。
